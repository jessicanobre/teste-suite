# Test Report 3 – Creating a New Contact

## Title: Create New Contact Record

__Description:__ This test verifies that the system allows creating a new contact with all required information.
Objective: To validate that users can register new contacts properly.
What is being tested: Contact creation functionality in the Contacts module.
Prerequisites:

* User logged in as Admin or Standard User.
* Access to Contacts module.

__Test Procedure:__

Log in to the system.

Navigate to Contacts > Create Contact.

Fill in all required fields: First Name, Last Name, Email.

Click “Save”.

Expected Result:
The new contact is saved and listed in the Contacts module.

Actual Result:
Contact is successfully created and appears in the contact list.

Result Analysis:
Test passed. All fields were saved properly.

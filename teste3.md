Objetivo do Teste
Verificar se a funcionalidade de criação de contatos no sistema CRM opera corretamente, garantindo que:

Campos obrigatórios sejam validados.

Dados sejam salvos com precisão.

A interface exiba confirmação da criação do contato.

Pré-condições
Acesso válido ao sistema CRM.

Navegação até a seção de Criação de Contatos.

1. Acesso à Funcionalidade de Criação de Contato
Navegou-se até a opção Create no menu do sistema.

Selecionou-se a categoria Contacts para iniciar o cadastro.

. Preenchimento dos Campos Obrigatórios
Nome:

First Name: Jessica

Last Name: Nicole (atualizado posteriormente para Nobre).

Preenchido com USBARD (corrigido para USAIDO no teste final).

Endereço de Email:

Correção: Substituído por test@gmail.com, marcado como Primary.

3. Preenchimento do Endereço Primário
